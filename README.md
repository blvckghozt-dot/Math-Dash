# MathDash · คิดเลขเร็ว

**MathDash** เว็บแอปฝึกคิดเลขเร็วตามแนวการแข่งขันศิลปหัตถกรรมนักเรียน
พัฒนาโดย **ครูอภิวัฒน์ ปาวงค์**

🔗 **ใช้งานได้ที่: https://mathdashmax.pages.dev/**

## ความสามารถ
- **3 โหมด**: เกม 24 (เลขโดด 4 ตัว → 24), เลขโดด 4 ตัว → คำตอบ 2 หลัก, เลขโดด 5 ตัว → คำตอบ 3 หลัก
- ตั้งเวลานับถอยหลังได้ (หรือไม่จับเวลา) มีปุ่ม **ดูเฉลย** และตรวจคำตอบที่นักเรียนพิมพ์ได้ทันที
- เลือกเครื่องหมายได้: + − × ÷ (ใช้ได้เสมอ), ยกกำลัง, ถอดราก, แฟกทอเรียล, ซิกม่าตามกติกา (ขอบเขตเป็นเลขโดดจากโจทย์, รูปแบบ i, i+i, i×i, iⁱ, i^(i!), i!/i), รากที่ n
- **สร้างแบบฝึกหัด PDF** ขนาด A4 หน้าละ 10 ข้อ (ช่องโจทย์ / วิธีการ / ทดเลข) กำหนดจำนวนข้อแต่ละโหมดได้ พร้อมเฉลยท้ายชุด
- เมนู **เครื่องมือช่วยคิด**: กรอกเลขโดดและคำตอบ แล้วเปิดคำใบ้ทีละขั้นจนถึงเฉลยเต็มพร้อมวิธีคิดทีละขั้นและวิธีอื่น ๆ
- เมนู **กระดาษแข่งขัน**: พิมพ์กระดาษคำตอบแบบใช้แข่ง (2–5 ช่องต่อหน้า) หรือดาวน์โหลด PDF / PNG 300 dpi
- เมนู **เทคนิคคิดไว**: วงเล็บ, คิดย้อนจากคำตอบ, ยกกำลัง/แฟกทอเรียลซ้อน, ซิกม่า, ตารางเลขที่ควรจำ, แผนการฝึก
- เมนู **กติกา & วิธีใช้**: อธิบายซิกม่าแบบเต็ม (Σ จาก i = 1 ถึง n) และวิธีใช้แอป
- ทุกโจทย์มีเฉลยจากระบบค้นหาคำตอบที่หาครบทุกวิธี (ถ้าทำให้ได้พอดีไม่ได้ จะเฉลยค่าที่ใกล้ที่สุด)

## เผยแพร่บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `mathdash`) แบบ Public
2. อัปโหลดไฟล์ `index.html` (และ `README.md`) ขึ้นไปที่ราก (root) ของ repo
3. ไปที่ **Settings → Pages** เลือก Source: *Deploy from a branch*, Branch: `main` / `(root)` แล้วกด Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/mathdash/`

ทั้งแอปอยู่ในไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม

## เผยแพร่บน Cloudflare Pages
1. เข้า Cloudflare Dashboard → **Workers & Pages → Create → Pages**
2. เลือก *Connect to Git* แล้วเลือก repo นี้ (Build command เว้นว่าง, Output directory: `/`) หรือเลือก *Upload assets* แล้วลากไฟล์ `index.html` ไปวาง
3. กด Deploy จะได้ลิงก์ `https://<ชื่อโปรเจกต์>.pages.dev`
